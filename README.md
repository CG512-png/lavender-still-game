# LAVENDER, STILL · 淡紫色

一部关于青春、回头、记忆与重新想起自己的 2D 互动叙事。

## 在线游玩

**https://cg512-png.github.io/lavender-still-game/**

建议佩戴耳机，并在游戏内开启全屏。首次点击“进入记忆”后，浏览器才会允许播放配乐、环境声与真人呼吸音效。

## 本地运行

```bash
npm install
npm run dev
```

## 生成发布版本

```bash
npm run build
```

发布由 GitHub Actions 自动完成。每次推送到 `main`，工作流都会重新构建并部署 GitHub Pages。
